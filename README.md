# Thesis CRM SystemВеб-орієнтована інформаційна система управління даними, розроблена в межах кваліфікаційної роботи.## Тема кваліфікаційної роботи**Розробка веб-орієнтованої інформаційної системи управління даними на основі сучасних веб-технологій**## Опис проєктуДаний проєкт є прикладною веб-орієнтованою інформаційною системою для централізованого управління структурованими даними. Система реалізована за CRM-подібним підходом і орієнтована на автоматизацію роботи малого бізнесу у сфері послуг, зокрема тату-салону.Система дозволяє:- вести облік клієнтів;- вести довідник послуг і категорій послуг;- створювати та редагувати записи на послуги;- розмежовувати права доступу між користувачами;- фіксувати історію зміни статусів записів;- вести журнал аудиту;- переглядати базову аналітику на головній сторінці.## Основний функціонал- автентифікація та авторизація користувачів;- рольова модель доступу:  - адміністратор;  - менеджер;  - співробітник;- CRUD-операції для:  - клієнтів;  - категорій послуг;  - послуг;  - записів;- фільтрація та пошук клієнтів;- фільтрація та пошук послуг;- фільтрація записів;- історія зміни статусів записів;- журнал аудиту;- dashboard із базовою аналітикою.## Використані технології- Python 3.14- Django 6- PostgreSQL- Django ORM- HTML- CSS- Bootstrap 5## Структура проєкту```textsrc/├── manage.py├── config/├── users/├── clients/├── services_catalog/├── appointments/├── audit/├── analytics/├── api/├── templates/└── static/
